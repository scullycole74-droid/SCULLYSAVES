Method summary

Stage 1 uses the unchanged 2025–26 pregame quartile rules (8 highest/lowest teams) and observed shot thresholds. Stage 2 trains an exploratory 2026–27-only Poisson count regression, chooses it only if it beats a simple shot-rate baseline on a chronological holdout, and estimates dispersion using actual residuals. The regression is recalculated after uploading updated current-season data.

Goaltender probability uses a simplified conditional full-game save rate applied to the shot-count distribution. It does not incorporate verified starter probability, relief appearances, actual playing-time risk, empty-net attempts, or market calibration.
